# Languages and translations

{% include where.html path="Shopify admin → Online Store → Themes → ⋯ → Edit default theme content" %}

Affluence includes translations for 31 languages: Bulgarian, Chinese (Simplified and Traditional), Croatian, Czech, Danish, Dutch, English, Finnish, French, German, Greek, Hungarian, Indonesian, Italian, Japanese, Korean, Lithuanian, Norwegian Bokmål, Polish, Portuguese (Brazil and Portugal), Romanian, Russian, Slovak, Slovenian, Spanish, Swedish, Thai, Turkish and Vietnamese.

## Changing wording

To change any text the theme prints (buttons, messages, labels), go to **Online Store → Themes → ⋯ → Edit default theme content** and search for the text.

## Adding a language to your store

Enable languages in **Settings → Languages**. The language selector appears in the header and footer once you have more than one language or market. Content that you wrote (products, pages, section text) must be translated separately, for example with Shopify Translate & Adapt.

## Right-to-left languages

When a shopper views your store in Arabic, Hebrew, Persian, Urdu or another right-to-left language, the whole layout mirrors automatically: text and menus start from the right, drawers that open from the left open from the right, carousels scroll the other way, and next/previous arrows point the way the shopper reads. There's nothing to set up. Add the language in **Settings → Languages** and translate its text with Shopify Translate & Adapt, since the theme doesn't include right-to-left translations.

Image hotspots and the before/after slider keep their positions, since they're tied to the picture rather than the text.
