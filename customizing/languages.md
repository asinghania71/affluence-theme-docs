# Languages and translations

Lush includes translations for 31 languages: Bulgarian, Chinese (Simplified and Traditional), Croatian, Czech, Danish, Dutch, English, Finnish, French, German, Greek, Hungarian, Indonesian, Italian, Japanese, Korean, Lithuanian, Norwegian Bokmål, Polish, Portuguese (Brazil and Portugal), Romanian, Russian, Slovak, Slovenian, Spanish, Swedish, Thai, Turkish and Vietnamese.

## Changing wording

To change any text the theme prints (buttons, messages, labels), go to **Online Store → Themes → ⋯ → Edit default theme content** and search for the text.

## Adding a language to your store

Enable languages in **Settings → Languages**. The language selector appears in the header and footer once you have more than one language or market. Content that you wrote (products, pages, section text) must be translated separately, for example with Shopify Translate & Adapt.
