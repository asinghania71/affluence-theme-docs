## Color schemes

Lush organizes color into **schemes**. A scheme is a named set of colors used together:

| Color | Used for |
|---|---|
| Background (and optional gradient) | The section's background |
| Text | Body and heading text |
| Accent | Highlights, links, and italic words in headings |
| Button / Button label | Primary buttons and their text |
| Secondary button label | Outline and secondary buttons |

Open **Theme settings → Colors** to edit schemes or add new ones. Every section has a **Color scheme** setting, so one edit to a scheme updates every section that uses it.

**Tips**

- Keep text and background contrast high. Test any custom scheme with a contrast checker; body text should reach at least 4.5:1.
- Reserve the accent color for things you want noticed. When everything is highlighted, nothing is.
- Use a dark scheme for one or two sections (a banner, the announcement bar) rather than the whole page, unless you picked a dark style.

## Typography

**Theme settings → Typography** controls fonts, the size scale, letter spacing and capitalization separately for headings and body text.

- Choose fonts from Shopify's font library so they are served from Shopify, not an external host.
- Use the **Font size scale** to make all text larger or smaller together.
- Headings can use a different capitalization from body text, for example uppercase headings with sentence-case body.

**Italic accent words.** In heading fields that support formatting, select a word and press the italic button. The word is set in the accent color, a quick way to add emphasis.

## Layout and spacing

**Theme settings → Layout** sets page width, page margin, grid gap and the space between sections. Smaller values give a denser catalog feel; larger values feel more editorial.

## Buttons, inputs and media

- **Buttons and inputs**: corner radius, border thickness, uppercase labels.
- **Media**: image corner radius and whether to use image focal points.
- **Image focal point**: after uploading an image in a section, set a focal point in Shopify so the important part stays visible when the image is cropped.
