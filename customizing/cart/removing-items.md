# Removing items

{% include where.html path="Theme settings → Cart → When an item is removed" styles="Remove immediately: Bloom · Ask to confirm: Lush, Noir, Catalog · Remove with undo: Atelier, Terra" %}

Decide what happens when a shopper removes an item from the cart. Asking first, or offering **Undo**, protects against accidental taps on mobile.

1. Open **Theme settings → Cart**.
2. Under **When an item is removed**, choose an option.
3. Click **Save**.

| Option | What happens |
|---|---|
| **Remove immediately** | The item disappears right away |
| **Ask to confirm** | A dialog asks the shopper to confirm before the item is removed |
| **Remove with undo** | The item is removed and an **Undo** button takes its place until the cart changes again |

![A "was removed from your bag" message with an Undo link, where the removed item used to be]({{ '/assets/images/cart/undo.png' | relative_url }})
*Remove with undo.*

To hide the remove button completely, open the **Cart** section, select the **Cart items** block and turn off **Show remove button**. Shoppers can still set the quantity to 0.
