# Gallery and media

Open **Products → Default product → Product information**. The gallery settings are at the top of the section.

## Gallery layout

| Option | Looks like |
|---|---|
| **Thumbnails on the right**, **on the left**, **below** | One large image with small thumbnails to switch between them |
| **Stacked** | All images one under another; product details stay in view as shoppers scroll |
| **Grid** | Images in a two-column grid |

![The Thumbnails below layout (left) and the Stacked layout (right)]({{ '/assets/images/product/gallery-layouts.png' | relative_url }})

On phones every layout becomes a swipeable carousel.

## Width and height

| Setting | What it does |
|---|---|
| **Desktop media width** | How much of the page width the gallery takes on desktop, for example 55%. Product details fill the rest |
| **Fit media to screen height** | Scales tall images down so the whole image fits on screen on desktop, without cropping. Applies to layouts with thumbnails |

{: .note }
Use a wider gallery for products that sell on looks (fashion, jewelry). Use a narrower one when shoppers need to read details (electronics, supplements).

## Zoom

- **Zoom images on hover** magnifies the image under the mouse pointer.
- **Theme settings → Media → Enable image zoom** adds a button that opens images full screen, on every device.

## Show only the selected variant's images

Turn on **Show only the selected variant's media** to show just the images for the color or style a shopper picks. For this to work, order your product media in the admin so each variant's image comes first, followed by its other images.
