# Product pages
{: .no_toc }

In the page picker, choose **Products → Default product**, then open the **Product information** section. The left half of the page is the media gallery. The right half is made of blocks that you can reorder, hide or remove.

## All blocks

| Block | What it shows |
|---|---|
| **Vendor**, **Title**, **Product rating**, **Price** | The product header |
| **Variant picker** | Options such as size and color |
| **Subscription options** | Purchase options from a subscription app |
| **Custom field** | A text box, checkbox or dropdown saved with the order |
| **Buy buttons** | Quantity, Add to cart and accelerated checkout |
| **Inventory status** | A low-stock message from your real inventory |
| **SKU**, **Pickup availability** | Extra details |
| **Estimated delivery date** | A delivery date range |
| **Quick order trigger** | A button that opens a table to order many variants at once |
| **Description** | The product description |
| **Collapsible row**, **Tabs**, **Specifications**, **Pop-up** | Extra content such as care, shipping or a size chart |
| **Share**, **Wishlist** | Share links and a save-for-later button |
| **Text**, **Icon with text** | Free text and short perks such as "Free returns" |
| **Complementary products** | Products that go well with this one |
| **Custom Liquid**, app blocks | Advanced content and blocks from installed apps |

Every setting is listed in the reference: [Product information](../../reference/sections/main-product/).

{: .note }
To use a different layout for some products, create a new template (**Products → Create template**) and assign it to those products in the admin under **Theme template**.
