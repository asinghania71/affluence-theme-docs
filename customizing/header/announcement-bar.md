# Announcement bar

A thin bar above the header for short messages such as free shipping offers, a sale or a new collection.

1. In the theme editor, find **Announcement bar** in the Header group. If it isn't there, click **Add section → Announcement bar**.
2. Click **Add block → Announcement** for each message (up to 6).
3. For each one, enter **Text**, an optional **Link** and an optional **Icon**.
4. Select the section and choose a **Display** mode.
5. Click **Save**.

| Display | What shoppers see |
|---|---|
| **Static** | The first announcement only |
| **Scrolling** | All announcements moving across the bar in a continuous loop |
| **Rotating** | One announcement at a time, with previous and next arrows |

![A rotating announcement bar with arrows on each side]({{ '/assets/images/header/announcement.png' | relative_url }})

## Useful settings

| Setting | What it does |
|---|---|
| **Scroll duration** | How long one full loop takes. Higher is slower |
| **Time per announcement** and **Transition** | For Rotating: how long each message shows, and fade or slide |
| **Show pause button** | Lets shoppers stop the scrolling. Leave this on: accessibility guidelines require it when movement lasts more than 5 seconds |
| **Show dismiss button** | Lets shoppers close the bar for the rest of their visit |
| **Color scheme** | The bar's colors |

{: .note }
Scrolling automatically stops for shoppers whose device asks for reduced motion. They see the first message, still and readable.
