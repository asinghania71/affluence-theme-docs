# Menu row and collection row

Two optional rows that sit under the header. Add them from the Header group with **Add section**. Each can be used once.

## Header menu row

A second row of menu links, useful for large catalogs.

![A second row of uppercase menu links under the header, with a "New" badge and a Store locator link]({{ '/assets/images/header/menu-row.png' | relative_url }})

| Setting | What it does |
|---|---|
| **Menu** | The menu to show |
| **Dropdown style** | **List**, or **Columns (full-width panel)**, which also shows third-level links |
| **Current page indicator** | An underline under the current page, or bold text |
| **Uppercase links**, **Alignment** | Text style and position |
| **Stick with the header** | The row stays under the header when scrolling |
| **On mobile** | **Scrolling strip of links**, or **Hide the row** |

**Blocks:**
- **Highlight**: adds a badge such as "New" or "Sale" next to a link, or shows it in the accent color. Choose the link with **Menu link**, so the badge stays put if you rename it.
- **Utility link**: one extra link at the end of the row on desktop, such as "Store locator".

## Header collection row

A strip of collections with small images, like category bubbles.

![Circular collection images with titles under each, centered below the header]({{ '/assets/images/header/collection-row.png' | relative_url }})

![The collection row on a phone, as a strip that scrolls sideways]({{ '/assets/images/header/collection-row-mobile.png' | relative_url }}){: .phone}
*On a phone.*

1. Add **Header collection row**.
2. Click **Add block → Collection** for each collection, and choose the **Collection**. Title and image fill in automatically; you can override them, and add a short **Badge**.
3. Choose a **Style**: **Pills**, **Underline**, **Text only** or **Image above title**, then an **Image shape**: **Circle** or **Square**.
4. Click **Save**.
