# Mobile menu

On phones, the menu opens from the ☰ icon. It uses the same **Main menu** as desktop.

![The mobile menu open, with menu links, a featured image, account and wishlist links, and the country selector]({{ '/assets/images/header/mobile-menu.png' | relative_url }})

Open the **Header** section and scroll to **Mobile menu**:

| Setting | What it does |
|---|---|
| **Drill-down navigation** | Opens each submenu on its own screen with a back button. Recommended for menus with three levels |
| **Show promo tiles** | Shows your [mega menu promos](../menus/) under the matching links |
| **Featured image** | An optional image under the links |

{: .note }
Preview the mobile menu with the phone icon at the top of the theme editor.
