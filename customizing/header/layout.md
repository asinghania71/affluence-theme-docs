# Header layout

Open the **Header** section in the Header group.

## Choose a layout

Pick an option under **Layout**:

| Layout | Looks like |
|---|---|
| **Logo on the left** | Logo left, menu next to it, icons on the right |
| **Logo in the center** | Menu left, logo in the middle, icons on the right |
| **Logo in the center, menu split on both sides** | Menu links split evenly around a central logo |
| **Logo above the menu** | Logo on its own row, the menu centered below |

![Four header layouts, top to bottom: logo on the left, logo in the center, menu split around the logo, logo above the menu]({{ '/assets/images/header/layouts.png' | relative_url }})

Set **Logo width** and **Logo width on mobile** to size the logo. Upload the logo itself in **Theme settings → Brand information**.

## Behavior when scrolling

| Setting | What it does |
|---|---|
| **Keep the header visible when scrolling** | The header stays at the top of the screen |
| **Hide when scrolling down** | Hides the header as shoppers scroll down and brings it back as soon as they scroll up. More room for products, especially on phones |
| **Shrink the header when scrolling** | Makes the header more compact after scrolling |
| **Logo size when scrolled** | Shrinks the logo after scrolling, for example to 80% |

The last three settings need **Keep the header visible when scrolling** turned on.

## Icons and extras

| Setting | What it does |
|---|---|
| **Show search** | The search icon and search drawer |
| **Cart icon shows** | **Item count**, or **Item count and total** |
| **Wishlist page** | Link a page with the Wishlist template to show the heart icon. See [Wishlist](../../wishlist/) |
| **Show country and language selectors** | Shown only if you sell in more than one country or language |
| **Show a divider below the header** | A thin line under the header |
