# Cart
{: .no_toc }

Lush has one **Cart** section. It powers the slide-out cart drawer and the full cart page, so you set everything up once and both match.

## Where to find the settings

| What | Where in the theme editor |
|---|---|
| What happens after a product is added, removing items, terms checkbox | **Theme settings → Cart** |
| Line items, free shipping bar, extra blocks | Open the **Cart** template in the page picker, then the **Cart** section |
| Which side the drawer opens from | **Theme settings → Layout → Drawers** |

Every setting is also listed in the reference: [Cart section](../../reference/sections/cart/) and [Theme settings → Cart](../../reference/theme-settings/#cart).
