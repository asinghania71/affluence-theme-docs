# Footer and newsletter
{: .no_toc }

## Footer blocks

The [Footer](../../reference/sections/footer/) is built from blocks: **Brand** (logo and description), **Menu**, **Signup**, **Image**, **Follow us** and **Text**.

![The footer with a brand column, menus and a newsletter signup]({{ '/assets/images/footer/footer.png' | relative_url }})

![The footer on a phone, with menus collapsed into tap-to-open rows]({{ '/assets/images/footer/footer-mobile.png' | relative_url }}){: .phone}
*On a phone.*

Choose a **Layout**:

| Layout | Looks like |
|---|---|
| **Columns** | Blocks side by side. Set **Columns on desktop** and **Columns on mobile** |
| **Centered** | Everything stacked and centered |
| **Wordmark** | Columns, with your brand name set very large across the bottom |

**Collapse menus on mobile** turns each footer menu into a tap-to-open list on phones, so the footer stays short.

Settings also toggle payment icons, the Follow on Shop button (requires Shop Pay), policy links, and country and language selectors.

## Social links

Add your profiles in **Theme settings → Social media**: Instagram, Facebook, Pinterest, TikTok, YouTube and X.

## Newsletter signup

Both the footer **Signup** block and the [Email signup banner](../../reference/sections/email-signup-banner/) use Shopify's customer form. Subscribers appear in **Customers** in your admin with email marketing consent. The banner can show an incentive badge such as "Get 10% off", a background image, and optional disclaimer text.

{: .note }
Offer only an incentive you actually deliver, for example by creating the matching discount code.
