# Bottom navigation bar
{: .no_toc }

`sections/bottom-nav-bar.liquid`

## Settings

| Setting | Type | Default | Notes |
|---|---|---|---|
| Color scheme | color_scheme | scheme-1 |  |
| Style | select | full | Full width sits flush against the screen edge. Floating is a rounded bar with space around it. Options: Full width · Floating. |
| Opacity | range | 100 | Lower values let the page show through the bar. 100% is solid. |
| Show labels | checkbox | on | Shows the text under each icon. |
| Hide when scrolling down | checkbox | off | Slides the bar away as shoppers scroll down and brings it back when they scroll up. |
