## Settings

| Setting | Type | Default | Notes |
|---|---|---|---|
| Style | select | pills | "Text only" hides the images. Options: Pills · Underline · Text only · Image above title. |
| Image shape | select | circle | Options: Circle · Square. |
| Image size | range | 40 |  |
| Image size on mobile | range | 32 |  |
| Alignment | select | center | Options: Left · Centered. |

| On mobile | select | scroll | Options: Scrolling strip of links · Hide the row. |
