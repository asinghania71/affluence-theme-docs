## Settings

| Setting | Type | Default | Notes |
|---|---|---|---|
| Background image | image_picker |  |  |
| Image overlay opacity | range | 40 | Darkens the image to keep text readable. |
| Image height | select | adapt | Options: Adapt to content · Small · Medium · Large. |
| Crop to fill | checkbox | off | On crops the image to fill the space. Off shows the full image, with empty space if its shape differs. |


**Layout**


| Setting | Type | Default | Notes |
|---|---|---|---|
| Content position (vertical) | select | middle | Applies only when a background image is set. Options: Top · Middle · Bottom. |
| Content position (horizontal) | select | center | Applies only when a background image is set. Options: Left · Center · Right. |
| Content alignment | select | center | Options: Left · Center · Right. |
| Show background box behind text | checkbox | off | Applies only when a background image is set. |
| Show text below image on mobile | checkbox | off | Applies only when a background image is set. |
