## Settings

**Banner**


| Setting | Type | Default | Notes |
|---|---|---|---|
| Show collection banner | checkbox | on |  |
| Show collection image | checkbox | on | Shown only when "Show collection banner" is enabled and the collection has an image. |
| Show collection description | checkbox | on | Shown only when "Show collection banner" is enabled. |
| Heading size | select | h1 | Options: Small · Medium · Large. |


**Filtering**


> Filters are configured in the Shopify Search & Discovery app. Filters added there appear here.


| Setting | Type | Default | Notes |
|---|---|---|---|
| Show filtering | checkbox | on | Configure filters in the Shopify Search & Discovery app. |
| Show sorting | checkbox | on |  |


**Layout**


| Setting | Type | Default | Notes |
|---|---|---|---|
| Let shoppers switch grid density | checkbox | on | Adds a compact and wide view toggle above the grid. The customer's choice is saved in their browser. |
| Products per page | range | 24 |  |
| Pagination | select | default | Options: Numbered pages · "Load more" button · Infinite scroll. |
| Columns on desktop | range | 4 | Default number of columns on desktop. Customers can switch to the wide view if the toggle above is enabled. |
| Columns on mobile | range | 2 | Default number of columns on mobile. Customers can switch to the wide view if the toggle above is enabled. |
| Wide view — desktop columns | range | 2 | Columns on desktop when customers switch to the wide view. Usually lower than the setting above. |
| Wide view — mobile columns | range | 1 | Columns on mobile when customers switch to the wide view. Usually lower than the setting above. |
