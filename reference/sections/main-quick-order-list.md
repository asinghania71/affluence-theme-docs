## Settings

**Table**


| Setting | Type | Default | Notes |
|---|---|---|---|
| Variants per page | range | 50 | Products with more variants are split across pages. The bulk order modal always shows 50 per page. |
| Show image column | checkbox | on | Shows each variant's image, or the product's featured image if the variant has none. The bulk order modal always shows images. |
| Show SKU column | checkbox | on | Variants without a SKU show an empty cell. The bulk order modal always shows SKUs. |
