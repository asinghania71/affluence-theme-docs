# Age verifier
{: .no_toc }

`sections/age-verifier.liquid`

Available on: footer.

## Settings

> Shows a gate on a visitor's first visit. It confirms age but does not verify identity, and needs JavaScript.


| Setting | Type | Default | Notes |
|---|---|---|---|
| Heading | inline_richtext | Are you 18 or older? |  |
| Text | richtext | <p>You must be of legal age to enter this site.</p> |  |
| Image | image_picker |  |  |
| Confirm button label | text | I'm 18 or older |  |
| Decline button label | text | I'm under 18 |  |
| Exit link | url |  | Where visitors who decline are sent. |
| Remember choice for | range | 30 |  |
| Color scheme | color_scheme | scheme-1 |  |
