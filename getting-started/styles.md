# Styles
{: .no_toc }

Affluence ships with six styles. A style sets the colors, fonts, corner shapes, spacing, default cart and wishlist behavior, and provides its own header, footer and page layouts. You can change any single setting afterward.

| Style | Look and feel | Best for |
|---|---|---|
| **Affluence** | Light, warm neutrals with gold accents, sharp corners, elegant serif headings | Beauty, home, jewelry |
| **Noir** | Dark, warm gold accent, sharp corners, classic serif headings | Luxury, fragrance, spirits |
| **Atelier** | Cool near-white, emerald accent, thicker button borders, uppercase headings | Fashion, design, art |
| **Bloom** | Light and soft, coral-pink accent, fully rounded buttons and cards, one friendly typeface | Lifestyle, gifts, wellness |
| **Terra** | Dark warm clay-brown, terracotta accent, slab-serif headings, medium rounded corners | Food, craft, outdoor |
| **Catalog** | Stark black on white, signal-red accent reserved for buttons, sharp corners | Large catalogs, electronics, hardware |

## Switching styles

Open the theme editor, click **Theme settings** (paintbrush icon), and choose a style under the preset picker. The whole store updates at once.

{: .note }
Choosing a different style replaces the colors, fonts and layout values you have changed. Pick your style first, then customize. If you want to keep a customized version, duplicate the theme before switching.

## What each style changes

- **Colors**: every color scheme (background, text, accent, buttons).
- **Typography**: heading and body fonts, size scale, capitalization.
- **Shape**: corner radius for buttons, inputs, cards, badges and images.
- **Density**: page margins, grid gaps and the space between sections.
- **Behavior defaults**: cart type and wishlist type.
- **Page layouts**: header, footer, home, collection, product, and about pages.
